## About me

I'm a software engineer at **Misr Exchange (a Bank Misr company)**, where I build and run the company's internal systems end to end — from requirements and database design to deployment and support — while also looking after IT infrastructure for **80 branches and the head office (400+ employees)**.

Working on both sides means I think about software the way operations sees it: it has to be secure, auditable, easy to support, and still running at 9 a.m. in every branch.

- 🏦 Building internal business systems in a regulated banking environment
- 🧱 Stack of choice: **Node.js / Express**, **Vue.js**, **PostgreSQL**
- 🖥️ Also hands-on with Windows Server, Active Directory, GPO, IIS, SQL Server, Cisco switching, VMware/Hyper-V
